Most of my repos are private (client work), so here's a fully white-labeled tour of the kinds of systems I build:

High-volume document processing backed by Rust and Go services. (Next.js · Laravel Octane · MySQL · Rust · Go)
- **Public Search & Discovery Platform** — a consumer-facing platform for searching verified listings and locating nearby facilities, with usage analytics and trend reporting. (Next.js · Laravel · MySQL)
- **Reference Data Platform** — a searchable, deeply structured catalog with guided filters, editorial content, change logs, analytics, and a Rust-rendered print publication. (Next.js · Laravel · MySQL · Rust)
- **Document & Records Management Hub** — an authenticated workspace with record classification, versioning, full-text search, audit trails, virus scanning, and secure PDF previews. (Next.js · Laravel · PostgreSQL · Redis)
- **Registration & Verification Platform** — a public registration system with verifiable reference numbers and an internal admin suite for staff. (Next.js · Laravel)
- **Inventory Management System** — stock, lot, and expiry tracking with allocation across multiple facilities. (Laravel · React · MySQL)
- **Workforce & Attendance System** — attendance, scheduling, leaves, and salary adjustments with role-based access control. (React · Vite · Laravel · MySQL)
